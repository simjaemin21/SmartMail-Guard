# SmartMail Guard 테스트 안내

## 실사용 Timely AI 화면에서 별도로 확인할 사항
- 에이전트 템플릿 `SmartMail Guard` 저장·불러오기
- 허용 모델 Solar Pro 4 선택 상태 확인
- `smartmail-guard-email-triage` 스킬 활성화 확인
- 가상 이메일 4개 유형(정상, 광고성 스팸, 피싱 의심, 장학금 사칭) 입력 후 결과 확인
- 스킬 사용 여부는 대화 응답뿐 아니라 가능한 경우 실행 기록으로 검증

## 로컬 프로토타입
실제로 Timely AI를 호출하는 프로그램이 아니라 별도 로컬 시연용 웹앱입니다.

```bash
python app/server.py
```

그 후 `http://127.0.0.1:8765`에 접속합니다. `UPSTAGE_API_KEY`가 설정되지 않았을 때는 **규칙 기반 데모**로 표시됩니다.

```bash
python tests/test_offline.py
```

8개 합성 테스트 데이터를 기준으로 규칙 기반 함수가 예상한 레이블을 출력하는지 확인합니다. 이 테스트는 AI 정확도 측정이 아닙니다.

## 안전
- 공개 저장소에 API 키, 비밀번호, 실제 메일 원문, 개인 식별 정보를 넣지 마세요.
- AI는 실제 발신자의 신원이나 URL 도착지를 자동 검증하지 않습니다.
- 실제 이메일 자동 삭제, 자동 분류 라벨 변경, Gmail 연동은 현재 구현되어 있지 않습니다.
