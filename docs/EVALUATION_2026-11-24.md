# SmartMail Guard 2.0 — 합성 테스트 검토 기록

**검토 날짜:** 2026-11-24  
**입력 데이터:** 합성 이메일, 실제 사용자 개인정보 없음  
**평가 자료:** 사용자가 Timely AI 대화에서 복사해 제공한 결과 텍스트

## 평가 결과

| 구간 | 분석 규모 | 보안 분류 잠정 일치 | 기타 |
|---|---:|---:|---|
| SMG-001~030 | 30 | 30/30 | 처음 25건은 정답 포함 CSV가 모델에 제공됨. 시간 표현 완전 일치 27/30 |
| SMG-031~046 | 16 | 15/16 | 정답 열을 제거한 CSV로 모델에 제시. 별도 검토는 사람이 수행 |

**위 수치는 Timely 응답 텍스트에 대한 수동 검토 기록이지 독립된 모델 벤치마크나 실서비스 정확도가 아닙니다.** 모델 사용 여부·실제 스킬 호출은 Timely 실행 기록을 통해 별도 확인해야 합니다. 오류 수정 지침을 평가 중/이후에 추가한 부분이 있어, 검토 수치를 개입 없는 최초 버전 성능으로 해석해서는 안 됩니다.

## 관찰한 오류와 한계

- **SMG-032:** 대상 학생과 필요 서류가 미확정인 장학금 공지를 `정상 메일 / 중요도 보통`으로 출력. 평가 기준은 `판단 보류 / 중요도 높음`.
- **SMG-004, 007, 010:** 행사 시점, 회신 기간, 프로모션 기간의 원문 시간 표현을 '기한 없음'만으로 처리해 누락. 엄격한 시간 표현 보존은 개발 30건 중 27/30.
- **SMG-011, 022:** 다른 이메일의 문구가 근거 설명에 섞인 징후.
- **SMG-016~020:** 개별 출력의 중요도(낮음)를 종합표에는 높음으로 옮긴 요약 오류. 위험도와 중요도 혼동.
- **SMG-022:** 예상 정답 기한을 비교표에서 잘못 옮김. 실제 본문에서 `10분 안에`를 잘 추출했으므로 기한 분석 오류는 아님.
- **SMG-026, 029, 032, 033, 040:** 원문에 없는 추가 표현, 제목 중복, 발신자 오기, 일본어 혼입 등의 출력 품질 문제.
- 피싱 사례에서 사용자에게 위험한 송금/비밀번호/OTP 제공을 권장한 경우는 전달된 분석 텍스트에서 발견되지 않았지만, 현실 세계에서의 보안을 보증할 수는 없습니다.

## 개선 조치

1. 메일별 원문 인용·ID·제목·발신자를 독립적으로 대조.
2. 원문 시간 표현을 놓치지 않고 타입(제출/회신/행사/시스템 점검/광고/공격 압박)별 분리.
3. 보안 위험·업무 중요도·보안 대응 우선순위를 서로 별도 출력.
4. 판단 근거가 부족한 메일에는 `판단 보류` 적극 고려.
5. 최종 표 작성 시 개별 분석 값을 복사·검증하고 한국어만 사용.

**중요:** 추가 16건 평가 이후 `SmartMail Guard 2.0 최종 품질 관리 규칙`을 더했으므로 **이 최종 수정 버전에 대한 독립적인 신규 데이터 성능 결과는 아직 없습니다.**

## 평가 설계 한계 및 향후 과제

- 모두 테스트 목적으로 작성한 소규모 합성 이메일이므로 현실의 피싱 기법·정상 발신 다양성을 반영하지 못할 수 있음.
- 개발 데이터는 분류별로 연속 배치돼 유형의 순서 편향이 있음.
- 16건은 정답 열을 모델에 주지 않았지만, 단일 대화에서 앞선 피드백과 규칙 수정이 이루어졌고 각 유형의 기대 결과를 평가자가 사전에 검토했음.
- 최종 지침을 고정하고 처음 보는 신규 혼합형 데이터를 별도로 제공해, 예측 저장 → 채점 → 오류 원문 분석을 재실행할 필요가 있음.
- 실제 이메일 서비스 연결, 발신 도메인 인증, 링크·첨부 검사, 자동 조치는 미구현.
